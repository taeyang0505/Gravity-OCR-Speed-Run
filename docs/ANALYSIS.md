# 시간 분석 (2.28 s → 1.97 s)

측정은 모두 RunPod L40S(약 14 CPU, 드라이버 595)에서 dev 402장, 새 프로세스로 3회 돌린 중앙값입니다.
리더보드(L40S, 8 vCPU)와의 비율은 318번 1.047, 319번 1.028이었습니다.

## 1. 시간 분해 (318번 구성, 2.18 s)

**GPU 커널 시간** (`tools/profiling/prof_run.sh`로 시간 측정 구간만 nsys로 기록, 2.15 s 구간):

| 스트림 | 커널 합 | 주요 커널 |
|---|---:|---|
| 언어 모델 (우선순위 높음) | 1,648 ms | FP8 GEMM 930, FlashInfer 어텐션 375, 정규화·양자화 96, lm_head argmax 79, SiLU 77, M-RoPE 72 |
| ViT (우선순위 낮음, 미리 실행) | 1,491 ms | FP8 GEMM 900, FA2 어텐션 216, SiLU 170, QK 정규화+RoPE 68 |
| GPU가 바쁜 시간 | 1,975 ms / 2,148 ms | 노는 시간 173 ms 중 145 ms가 ViT가 끝난 뒤 마지막 0.5 s에 몰림 |

**요청 타임라인** (1등 팀의 `TRACK2_LOG=2` 기록, `tools/profiling/timeline.py`, `rounds_per_req.py`):

- 언어 모델 투입은 **ViT가 끝나는 속도에 맞춰** 진행됩니다. ViT 묶음(약 1.6만 패치)이 끝날 때마다 그만큼만 들어가고,
  402장이 모두 들어가는 시각은 1.9 s였습니다. 동시 처리는 한도 160 중 70~140이었습니다.
- 마지막에 끝나는 요청은 두 종류였습니다. **일찍 들어간 긴 표**(가장 긴 표 1,428토큰, 46라운드, 라운드당 약 40 ms)와
  **중간 순번의 긴 한국어 텍스트**(라운드당 약 8토큰만 맞아 36라운드)입니다.
- 초안 길이 25에서 라운드당 확정 토큰은 표 약 23, 수식 약 12, 텍스트 약 8~13입니다.
  표는 창이 모자라고(전부 맞는 라운드 77%), 텍스트·수식은 창의 절반 이상이 버려집니다.

## 3. 적용한 최적화

**계산량 줄이기 (서버 1대, 품질 손해 거의 없음)**

| 변경 | 시간 | dev 품질 변화 |
|---|---:|---|
| 수식 글자 14 px | 2.15 s | 수식 +0.1 |
| 빈 묶음 건너뛰기 (표 제외, 동기화 없음) | 2.15 s | 텍스트 −0.16 |
| ViT gate_up + SiLU 합친 커널 | 2.16 s | 없음 (가장 흔한 1.6만 패치 묶음에서는 결과가 비트 단위로 같음) |
| 축소 대상 패치 256개 이상 | 2.14 s | 텍스트 −0.17 |
| 네 가지 함께 | **2.06 s** | 텍스트 −0.25 |

**서버 2대 (CUDA MPS, 같은 GPU)**

| 표 서버 / 텍스트·수식 서버 | 표 서버 MPS 우선순위 | 계산량 절감 | 시간 |
|---|---|---|---:|
| 초안 33 / 17 | 같음 | 없음 | 2.23 s |
| 초안 33 / 17 | 낮춤 | 없음 | 2.14 s |
| 초안 25 / 13 | 낮춤 | 없음 | 2.11 s |
| 초안 33 / 13 | 낮춤 | 없음 | 2.08 s |
| 초안 25 / 13 | 낮춤 | 4가지 | 1.91 s |
| **초안 33 / 13** | **낮춤** | **4가지** | **1.91 s (1.90 / 1.91 / 1.91)** |

텍스트 서버는 초안이 짧을수록(25 → 17 → 13) 빨랐습니다. 텍스트는 어차피 라운드당 8~13토큰만 맞아서, 창을 줄이면
라운드 계산량만 줄고 라운드 수는 거의 늘지 않습니다. 표 서버는 창이 길수록 라운드가 줄지만 GPU를 더 쓰므로,
MPS 우선순위를 낮춰 텍스트 서버의 라운드를 방해하지 않게 했습니다. 최종 구성에서 마지막에 끝나는 요청은 모두 표입니다.

측정용 확인: 가장 긴 요청 5개를 뺀 dev(397장)는 2.04 s였습니다. 계산량은 약 4% 줄었는데 시간은 6.4% 줄어,
긴 요청이 실제로 끝 시각을 붙잡고 있음을 보여 줍니다.
